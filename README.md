# 🛍️ Vitrine Web de Vendas

Uma aplicação web responsiva para exibição de produtos, desenvolvida com **React**, **Vite** e **TypeScript**.  
Ideal para apresentar itens de forma organizada, com design moderno e rápido carregamento.

## 📌 Funcionalidades

- Exibição de lista de produtos com imagem, nome, descrição e preço
- Layout responsivo para celular, tablet e desktop
- Organização por categorias

## 🛠 Tecnologias Utilizadas

- **React** – Biblioteca para construção da interface
- **Vite** – Build rápido e ambiente de desenvolvimento
- **TypeScript** – Tipagem estática e segurança no código
- **CSS / Tailwind
